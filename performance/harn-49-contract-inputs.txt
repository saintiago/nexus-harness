5. What the contract now checks about itself
--------------------------------------------

`tests/validation-cache.test.ts` gained one case — "declares every file the contract task itself
inspects" — which walks the same set the contract parses (every test file on disk, every file
reachable from a policy group's files by relative import, every literal path those files read, and
the hand-named reads the walk cannot follow) and fails when `test:policy:config` does not declare
one of them. The configuration group is 144 cases now; the policy layer is 581.
